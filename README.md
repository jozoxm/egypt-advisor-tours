# Egypt Advisor Tours

## 🚀 Quick Start (Required!)

**⚠️ IMPORTANT: You MUST install dependencies before running the website!**

```bash
cd client
npm install    # ← Run this FIRST (takes 2-3 minutes)
npm start      # ← Then run this
```

Your browser will open to `http://localhost:3000` ✅

**Common Error?** If you see `'react-scripts' is not recognized`, you forgot to run `npm install` first. See [SETUP.md](./SETUP.md) for troubleshooting.

---

## Project Overview
Egypt Advisor Tours is a travel agency website designed to help travelers plan their visits to Egypt with ease. It provides useful information about various tours, attractions, accommodations, and travel tips to create unforgettable experiences.

## 📦 Installation Instructions

### Prerequisites
- Node.js v14 or higher ([Download here](https://nodejs.org/))
- npm (comes with Node.js)

### Setup Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jozoxm/egypt-advisor-tours.git
   ```

2. **Navigate to the client directory:**
   ```bash
   cd egypt-advisor-tours/client
   ```

3. **Install dependencies (REQUIRED!):**
   ```bash
   npm install
   ```
   ⏱️ This takes 2-3 minutes and installs ~1,300 packages

4. **Start the development server:**
   ```bash
   npm start
   ```
   ✅ Browser opens automatically to `http://localhost:3000`

### Production Build

To create an optimized production build:
```bash
cd client
npm run build
```

The build files will be in the `client/build/` folder, ready for deployment.

## ⚠️ Troubleshooting

**Error: 'react-scripts' is not recognized**
- **Solution:** Run `npm install` in the `client` folder first

**Error: Port 3000 already in use**
- **Solution:** Run `PORT=3001 npm start` to use a different port

**More issues?** See [SETUP.md](./SETUP.md) for comprehensive troubleshooting.
