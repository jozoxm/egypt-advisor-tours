## 🌐 Deploy to Hostinger - Step by Step

### Step 1: Build Production Version

```bash
cd client
npm run build
```

### Step 2: Upload Files

**Upload everything from `client/build/` folder to `/public_html/` on Hostinger**

**Option A: Hostinger File Manager** (Easiest)
1. Log into Hostinger dashboard
2. Open File Manager
3. Navigate to `/public_html/`
4. Upload all files from `build/` folder

**Option B: FileZilla FTP Client**
1. Download FileZilla
2. Connect with your Hostinger FTP credentials
3. Drag files from local `build/` to remote `/public_html/`

### Step 3: Configure Domain & SSL

1. Point domain to Hostinger nameservers
2. Add domain in Hostinger dashboard
3. Install Free SSL certificate
4. Wait for DNS propagation (up to 48 hours)

### Step 4: Test Your Live Website

Visit: `https://egyptadvisortours.com`
